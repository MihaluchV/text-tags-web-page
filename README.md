# text-tags-web-page
# Веб-дизайн. Текстові теги HTML

Інтерактивне завдання з інформатики для учнів 11 класу. Мета — повторити текстові теги HTML і навчитися застосовувати їх на практиці.

Це один файл `index.html`: без установлення, без бібліотек і без підключення до інтернету.

## Зміст завдання

| Етап | Що робить учень | Бали |
|------|-----------------|------|
| 1. Зіставлення | Обирає тег за описом і прикладом, як він виглядає в браузері | 20 |
| 2. Тест | Відповідає на 12 питань, одразу бачить пояснення | 12 |
| 3. Допиши код | Перетягує теги з панелі в пропуски коду (є зайві теги) | 12 |
| 4. Практика | Відтворює сторінку за зразком у редакторі з миттєвим переглядом | 12 |
| 5. Підсумок | Бачить бали й помилки за етапами, зберігає результат як зображення PNG | — |

Теги, що повторюються: `h1`–`h4`, `p`, `br`, `b`, `strong`, `i`, `em`, `u`, `strike`, `big`, `small`, `mark`, `sub`, `sup`, `q`, `blockquote`, `address`, `code`, `pre`, `abbr`.

## Як запустити

**Локально.** Завантажте `index.html` і відкрийте його в будь-якому сучасному браузері.

**Через GitHub Pages.**
1. Створіть репозиторій і завантажте в нього `index.html` та `README.md`.
2. Відкрийте **Settings → Pages**.
3. У розділі **Build and deployment** оберіть **Deploy from a branch**, гілку `main` і папку `/ (root)`.
4. Через хвилину сторінка буде доступна за адресою `https://<ваш-логін>.github.io/<назва-репозиторію>/`.

## Особливості

- Працює на комп'ютері й на телефоні. Перетягування підтримує миші та сенсорні екрани. Є й запасний спосіб: торкнутися тега, а потім пропуску.
- Підлаштовується під світлу й темну тему пристрою.
- Результати не передаються на сервер і ніде не зберігаються. Підсумок формується лише на пристрої учня.
- Кнопка «Зберегти як зображення» створює файл `pidsumok-tekstovi-tehy.png`.

## Як змінити завдання

Усі дані лежать на початку блоку `<script>` у файлі `index.html`:

- `M` — приклади для зіставлення;
- `Q` — питання тесту;
- `F` та `DIST` — рядки коду та зайві теги для перетягування;
- `R` — теги, які перевіряє практика (зображення-зразок у вкладці «Практика» вбудовано в код).
